# Команды Git для практики

Шпаргалка помогает выбрать команду Git и проверить, в какой папке и ветке её выполнять. Команды вводятся в Git Bash на Windows или Терминале на macOS.

## Содержание

Подробные команды и пояснения: [git-commands.md](git-commands.md).

Обозначения: `<URL>`, `<URL-оригинала>` и `<HASH>` заменяйте своими значениями без угловых скобок. `main` — основная ветка, `improve-topic` — пример рабочей ветки.

В клоне своего fork `origin` ведёт в ваш fork, `upstream` — в оригинал автора. Перед `merge`, `pull` и `cherry-pick` проверяйте `git status`. При конфликте сначала исправьте и проверьте файлы, затем завершайте начатую операцию.
